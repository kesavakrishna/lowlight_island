# Lowlight Island

A Windows Godot prototype about escaping a randomly generated island while a creature hunts after dark. Carry the battery to the radio, power it, and reach the dock before the six-minute rescue window closes.

## Run the game

Open [the game project](outputs/LowlightIsland-v2/project.godot) in Godot 4.5.1 and press F5. To use the Windows launchers, set `GODOT_EXE` to the full path of your Godot executable or place the portable engine files in `work/godot/`.
